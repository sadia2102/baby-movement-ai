# Fixed protocol: first InfAnFace training-only feasibility pilot

**Written before real model execution: 28 October 2026.** Protocol `infanface-train-fit-v1`, starting Git commit `a2c682e`. This is **ground-truth-crop, training-only optimization smoke testing**. No validation/test/benchmark/patient-independent or clinical accuracy claim is permitted. Unknown subject/video/source groups remain unknown. The original research plan and historical reports are preserved.

- **Pool and selection:** parse the shared CSV index, discard official test rows before interpreting their landmark payloads, and validate only official training annotations. Rank training samples by SHA-256 of UTF-8 `infanface-train-fit-v1|42|<image-set>/<filename>`; break ties by image set and filename. Select the first **32**, without replacement. Selection is independent of image quality, geometry, model results or inferred identity. Decode only the selected training images. No replacements after exclusions and no project split creation. Record selected private references and annotation/selection hashes.
- **Prior evidence and review gate:** eight previous official training overlays support gross stored-raster correspondence, including consistent image/landmark EXIF handling in two rotated examples. Exact origin/global frame remain **UNVERIFIED**. Prepare private annotation-only crop panels for every usable selected image. Require a recorded qualitative review supporting gross correspondence before model creation/execution. Any unsupported gross alignment stops the pilot without changing selection/configuration or substituting examples. This is a single assistant review, not independent anatomical adjudication.
- **Coordinate assumptions:** explicitly hypothesize source base-0 pixel centres and a **stored-pixel annotation frame**, retaining the working pixel-edge convention (raw numbers +0.5). These hypotheses remain UNVERIFIED. Use **stored** orientation for both raster and points, including absent or invalid EXIF tags. Never rotate pixels alone, guess an orientation or apply a silent tag override. Record tag/invalid-tag counts. Historical aggregate test findings are references only; do not open test images or interpret test landmarks for decisions.
- **Fixed crop/input:** derive an axis-aligned ground-truth box from present finite landmarks within the assumed source footprint. Require at least three eligible points and nonzero horizontal/vertical span. Expand each side by **20% of its corresponding landmark span**, floor left/top, ceil right/bottom, and clip **box edges only** to source raster bounds. Record every box explicitly. Do not clamp/change coordinates. Use the existing uniform BICUBIC affine resize and centred black padding to **32×32**, white alpha compositing, RGB CHW float32 `[0,1]`. No augmentation, detector, learned normalization, alternative crop margin or parameter sweep. Label all results ground-truth-crop feasibility; the crop uses labels and does not measure face-detection performance.
- **Validity/exclusions:** retain original and transformed coordinates. Loss eligibility is present AND source/crop/output footprint checks, never inferred visibility. Missing slots remain missing; out-of-bounds slots remain numerical and masked. Decode/crop failures or zero eligible targets exclude an image with a private reason. Do not replace excluded examples. Record selected/decoded/usable images, point denominators and separate mask counts (which can overlap). Stop before training if no usable example remains. No exclusion decision uses model predictions. Prior out-of-bounds/test findings are not reopened.
- **Model/init:** unchanged `SmallLandmarkCNN`, 75,832 parameters, 68 unconstrained normalized pixel-edge coordinate pairs. **Fresh** seeded random initialization; do not load synthetic/pretrained checkpoints. CPU only, float32, one thread, deterministic algorithms, zero loader workers. Cache only prepared tensors in process memory.
- **Fixed optimization:** seed **42**, shuffle-loader seed **43**, batch **8**, ordinary Adam LR **0.003**, betas **(0.9,0.999)**, eps **1e-8**, weight decay **0**, no scheduler/AMP/accumulation. Masked coordinate MSE over eligible x/y scalars. Run exactly **20 epochs**, at most **80 optimizer steps** for 32 usable examples. Skip entirely missing-target batches; fail an entirely unsupervised epoch. No early stopping or choice of a best epoch based on fit. Save **only the fixed final epoch checkpoint**, with optimizer/RNG/config/provenance and digest. Check reload on the same training inputs; this is not another training run.
- **Metrics:** record initial and final deterministic **training-set fit** on the same usable subset, plus epoch optimization loss. Primary: image-macro Euclidean landmark error in **32×32 input-edge pixels**. Secondary: image-macro Euclidean error mapped back to original source pixel units using each inverse transform. Report masks and coverage. All 68 source slots are supported without claiming canonical anatomical identities. No anatomical NME, eye denominator, detection accuracy, held-out accuracy, confidence intervals over patients or seizure metric.
- **Stopping/failure rules:** stop on checksum/protocol/config/selection/source mismatch, test sample/pixel access attempt, invalid bounds, unapproved/unsupported alignment review, nonfinite model/eligible-target/loss/gradient, empty usable data or a zero-supervision epoch. Maximum 20 epochs/64 selected examples are enforced by code; this fixed run selects 32. A failure is recorded and does not authorize a rerun or new settings. A finite run completes even if fit fails to improve; report that outcome without tuning.
- **Records/privacy:** use one fresh ignored `runs/infanface-train-pilot-2026-10-28/`. Store protocol/config/code/environment/Git/archive/selection hashes, private selected/usable records and boxes, annotation-only QC panels and review, counts, epoch losses, initial/final training errors, fixed-final checkpoint/digest, reload result and status. Preserve all prior files. Emit only aggregates. No new dependencies, datasets/weights, contacts, uploads/pushes, PRs or background jobs.

This protocol authorizes no stronger scientific interpretation of training fit. The next experiment must be proposed after the single run, with grouping/coordinate and comparison needs left explicit.
